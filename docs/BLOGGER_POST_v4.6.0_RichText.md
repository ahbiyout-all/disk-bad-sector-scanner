## ✨ v4.6.0 핵심 신기능 및 개선 사항

### 1. D3.js 실시간 섹터별 읽기 속도 및 I/O 레이턴시 분포 히스토그램
표면 검사 중 발생하는 각 섹터 블록의 응답 지연시간(ms)과 읽기 속도(MB/s) 분포를 D3 기반 히스토그램으로 실시간 시각화하여, 배드섹터로 발전하기 전 단계인 **ECC 읽기 재시도 전조 증상**을 직관적으로 판별할 수 있습니다.

- **검사 방식(Quick vs Full) 연동 통계 정밀도 자동 조정**
  - **Quick 모드**: 8-Bin 고속 샘플링 정밀도, 소수점 1자리(0.1ms) 및 표본 오차한계(±ms) 표시
  - **Full 모드**: 20-Bin 초정밀 전수 분석, 소수점 2자리(0.01ms) 백분위(P50 / P95 / P99) 및 지터(σ) 산출
  - 필요 시 차트 우측 상단 셀렉터에서 `자동 / 고속 샘플링(8-Bin) / 초정밀 분석(20-Bin)` 수동 전환 가능
- **100ms 이상 `Slow/Critical` 섹터 오렌지/레드 하이라이트 및 실시간 요약 카운터**
  - D3 빈(Bin) 경계를 `100ms` 기준으로 정확히 분할하여 정상 구간과 지연 구간이 섞이지 않도록 분리했습니다.
  - **100ms 이상 지연 구간 막대**를 고대비 경고 **오렌지-레드 그라데이션 + 대각선 해치 패턴 + 강조 테두리**로 하이라이트하고, 위험(>500ms) 및 I/O 오류 구간은 선명한 레드 컬러로 구분합니다.
  - 차트 상단 헤더에 **`Slow/Critical (≥100ms) 총 N개 (비율%)`** 실시간 요약 카운터가 상시 표시되어 스캔 중 이상 섹터 누적량을 즉시 파악할 수 있습니다.
- **LBA 상세 드릴다운 인스펙터**: 히스토그램 막대를 클릭하면 해당 지연 구간에 속한 섹터의 시작 LBA, 지연시간, 속도 목록이 즉시 펼쳐져 문제 영역을 바로 추적할 수 있습니다.

### 2. S.M.A.R.T. 제조사 임계치 초과 시각 경고 및 툴팁 (`HealthSummaryDashboard`)
- 재할당 섹터 수(`0x05`), 보류 중인 섹터(`0xC5`), 오프라인 회복 불가(`0xC6`), 온도(`0xC2`) 등 주요 S.M.A.R.T. 속성이 제조사 임계값(Threshold)을 초과하거나 근접할 경우 경고 배지, 행 하이라이트, 상세 원인 툴팁으로 즉시 안내합니다.

### 3. Windows IOCTL/WMI 32-드라이브 전수 탐색 및 제로 더미(Zero-Dummy) 실측 전환
- Windows 커널 `\\.\PhysicalDrive0` ~ `PhysicalDrive31` 전수 조사 및 논리 볼륨 문자 매핑을 C++, Rust, Tauri IPC 계층에 통합하여 외장 USB/NVMe/SATA 장치 인식률을 높였습니다.
- C++, Rust, Tauri, TypeScript 전 계층에 남아 있던 하드코딩 폴백과 난수 시뮬레이션을 모두 제거하고, 실제 커널 IOCTL 및 브라우저 실측 API(OPFS / File System Access / StorageManager)로 전면 교체했습니다. (미지원 하드웨어 센서는 임의 값 대신 `N/A`로 정직하게 표기)

## 📊 Quick vs Full 히스토그램 정밀도 비교 요약

| 구분 | Quick 모드 (고속 샘플링) | Full 모드 (초정밀 전수 분석) |
| :--- | :--- | :--- |
| **D3 히스토그램 해상도** | **8-Bin** 구간 분할 | **20-Bin** 세밀 구간 분할 |
| **레이턴시 소수점 정밀도** | **0.1 ms** 단위 | **0.01 ms** 단위 |
| **통계 오차 표시** | 유한 모집단 표본 오차한계(`±ms`) 표기 | 100% 전수 실측 분포 집계 |
| **100ms+ 하이라이트** | 오렌지/레드 경계 분리 및 상단 실시간 카운터 | 오렌지/레드 경계 분리 및 상단 실시간 카운터 |
