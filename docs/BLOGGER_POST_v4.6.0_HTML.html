RELEASE v4.6.0 · 2026-11-13

Disk Bad Sector Scanner v4.6.0 정식 업데이트

D3.js 실시간 섹터 I/O 레이턴시 히스토그램, 100ms+ Slow/Critical 오렌지·레드 하이라이트, 검사 방식(Quick/Full) 연동 정밀도, 32-드라이브 Windows IOCTL/WMI 탐색 및 전 계층 제로 더미(Zero-Dummy) 실측 엔진 적용

안녕하세요, AhBiYout (CISNet)입니다. 물리 하드 드라이브(HDD), SSD, NVMe 및 외장 USB 저장장치의 표면 결함과 배드섹터(Bad Sector)를 실시간으로 분석·수복하는 Disk Bad Sector Scanner가 v4.6.0으로 업그레이드되었습니다.

1. D3.js 실시간 섹터별 읽기 속도 및 레이턴시 히스토그램

단순 정상/불량 개수 집계를 넘어, 스캔 중 수집되는 모든 섹터 블록의 응답 지연시간(ms)과 읽기 속도(MB/s)를 D3 히스토그램으로 실시간 시각화합니다. 배드섹터로 번지기 전 나타나는 ECC 읽기 재시도 전조 증상(긴 꼬리 왜도 · 이중 분포)을 즉각 포착할 수 있습니다.

🔥 100ms 이상 Slow/Critical 섹터 경고 하이라이트 & 차트 상단 실시간 카운터
  • 고대비 오렌지/레드 하이라이트: 지연 ≥ 100ms 구간 막대를 오렌지-레드 그라데이션(#EF4444 ↔ #F97316), 대각선 해치 패턴, 강조 테두리 및 음영 배경으로 명확히 구분합니다.
  • 엄격한 100ms 빈(Bin) 경계 분할: 로그 티어 및 D3 균등 분포 모두에서 100ms 경계를 강제 분할하여 정상 블록과 지연 블록이 한 막대에 섞이지 않습니다.
  • 차트 상단 실시간 요약 카운터: 헤더 우측에 Slow/Critical (≥100ms) 총 N개 (비율%) 실시간 카운터가 상시 표시됩니다.
  • LBA 상세 드릴다운: 강조된 막대를 클릭하면 해당 구간의 시작 LBA, 응답시간, 전송속도 목록을 즉시 조회하고 수복 대상으로 선택할 수 있습니다.

2. 검사 방식(Quick vs Full) 연동 통계 정밀도 설정

현재 선택된 드라이브의 검사 방식에 따라 히스토그램 통계 해상도와 정밀도가 자동으로 최적화되며, 필요 시 수동 전환도 지원합니다.

항목 Quick 모드 (고속 샘플링) Full 모드 (전수 정밀 분석)
D3 빈(Bin) 해상도 8-Bin 고속 구간 분할 20-Bin 초정밀 구간 분할
응답시간 소수점 정밀도 0.1 ms (소수점 1자리) 0.01 ms (소수점 2자리)
오차 신뢰구간 표시 표본 오차한계(±ms) 실시간 산출 전수 조사 기준 분포 집계

3. 32-드라이브 네이티브 탐색, S.M.A.R.T. 경고 및 제로 더미 실측 전환

  • Windows IOCTL/WMI 32-드라이브 전수 탐색: \\.\PhysicalDrive0~31 및 논리 볼륨 매핑을 C++/Rust/Tauri 전 계층에 적용하여 SSD/HDD/NVMe/외장 USB 인식률을 대폭 강화했습니다.
  • S.M.A.R.T. 제조사 임계치 초과 시각 경고: 재할당 섹터, 보류 섹터, 온도 등 핵심 속성이 제조사 Threshold를 초과할 때 시각적 경고 배지와 상세 진단 툴팁을 표시합니다.
  • 전 계층 더미 코드 제거(Zero-Dummy Policy): C++, Rust, Tauri, TypeScript 전반의 하드코딩 폴백을 제거하고 커널 Direct I/O 및 브라우저 실측 API(OPFS / File / StorageManager)로 완전 교체했으며, 미지원 센서는 N/A로 정직하게 표기합니다.
